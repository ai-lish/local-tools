# HKDSE Split Question

瀏覽器內的 HKDSE PDF 逐題切圖工具。把一份試卷 PDF 拖入頁面，逐題確認起點及終點，再輸出穩定命名的 PNG 或 JPG。檔案只在目前瀏覽器處理，不會上載到 Google Drive、GAS 或其他伺服器。

P1 的「試題答題簿」就是題目來源；選擇「卷別：P1」及「內容：題目」即可處理。答題簿可能有側邊提示、外框及答題線，可用左右裁切位置及題目上下界線決定輸出內容。

## 階段一範圍

- 拖放或選取 PDF。
- 顯示 PDF 頁面縮圖及目前頁面預覽。
- 按題數建立題目表。
- 以頁碼及頁面高度百分比設定每題的起點及終點。
- 以頁面寬度百分比設定統一的左右裁切範圍，適合 P1 試題答題簿。
- 支援跨頁題目；跨頁範圍會上下拼接為一張長圖。
- 每題可直接修改輸出檔名。
- 產生逐題圖片及 manifest.csv，或打包成 ZIP。

題目界線目前由使用者確認，工具不會自行猜測題號、課題、分數或甲乙部內容。M1、M2、P1 可以先用初始部份值，再在題目表逐題核對；P2 不顯示部份欄。

## 使用方法

1. 在 local-tools 根目錄啟動本機靜態伺服器：

       python3 -m http.server 8765

2. 開啟 http://127.0.0.1:8765/tools/hkdse-question-split/。
3. 拖入一份 PDF。
4. 選擇卷別、年份、語言及內容類型。
5. 輸入該份 PDF 的實際題數，按「建立題目表」。
6. 選取一行，按「設定起點」或「設定終點」，再在右側頁面按一下；亦可以直接編輯頁碼及百分比。
7. 如需移除答題簿外框或側邊提示，設定左／右裁切位置；一般 PDF 保持 0%／100%。
8. 核對每一行顯示為可輸出的狀態，按「下載逐題 ZIP」。

頁面高度百分比以 PDF 頁面的頂部為 0、底部為 100。起點及終點可以位於不同頁，適合卷一乙部的跨頁長題。

## 界線範本

範本可保存目前題目表的界線及輸出設定，方便續做或套用到版面相近的另一份 PDF。範本不會保存 PDF 內容、檔案名稱、檔案路徑、縮圖或頁面像素。尚未完成的題目界線也可存成草稿；匯出圖片 ZIP 前，仍須按「輸出前檢查」完成所有界線。

### 操作例子

- **存檔續做：**設定若干題的起點及終點後，按「匯出範本 JSON」下載備份。日後重新開啟工具、載入同一份 PDF，匯入 JSON，核對摘要後按「套用到目前題目表」，即可接續微調。
- **中英版互套：**先完成中文卷的範本，再載入英文卷並匯入。頁數不同會顯示警告；可設定整體頁碼位移及整體上下位移，預覽受影響題數，再套用及逐題修正。套用會同時套用範本的輸出設定；中文範本套到英文卷後，請把語言切為英文，未自訂的檔名會按現有命名規則更新。
- **相近年份／版面：**匯入前一年度範本後，按預覽核對各題界線。即使題目位置變化較大，仍可套用後逐題修改；超出目標 PDF 頁數的界線會保留並標示錯誤，不會自動刪除或截斷。

「儲存到此瀏覽器」會以白名單鍵 `hkdse-question-split.templates.v1` 儲存範本清單；可預覽／套用、改名或刪除。刪除及覆蓋未匯出的界線都會先在頁面內確認。瀏覽器儲存被封鎖或容量不足時，工具會顯示提示；匯入及匯出 JSON 仍可使用。重要範本建議另行匯出備份。本機儲存只在目前瀏覽器設定檔內，不會同步到雲端。

整體頁碼位移會加到每個已設定的起點及終點頁；上下位移以「百分點」相加或相減。套用前會顯示變更題數；頁數不一致會警告但仍可套用。位移後若頁碼或百分比超出目標 PDF 範圍，或題目界線重疊／次序衝突，會保留原值並列出錯誤，讓使用者逐題修正，不會自動夾限、刪除或截斷。

### JSON 欄位

| 欄位 | 用途 |
| --- | --- |
| `format`、`version` | 格式識別及版本；目前是 `hkdse-question-split-template`、v1。 |
| `id`、`name`、`createdAt`、`updatedAt` | 範本識別、名稱及建立／更新時間。 |
| `paper`、`year`、`language`、`kind` | 卷別、年份、語言及題目／評卷參考類型。 |
| `outputFormat`、`dpi`、`sectionEnd` | PNG／JPG、輸出 DPI，以及「甲部最後題號」設定。 |
| `leftPercent`、`rightPercent` | 左右裁切百分比。 |
| `sourcePageCount` | 建立範本時來源 PDF 的頁數，用於套用時提醒核對。 |
| `boundarySets.questions` | 每題題號、部份、輸出檔名，以及起點／終點頁碼與頁面高度百分比。未開始的一組座標可同時留空；已填的一側須同時有頁碼及百分比。 |
| `boundarySets.answers` | v1 固定為 `null`，只為日後擴展預留欄位。 |

日後如需在同一範本加入答案界線，可把 `boundarySets.answers` 擴展為另一組逐題界線；本階段只讀寫題目界線，不提供答案組、題目與答案一套過、界線自動建議或 Drive 連接。範本驗證沿用目前題目列的頁碼、百分比、題號、甲乙部、檔名、起終點次序及題目重疊規則；錯誤以繁體中文列出，無效 JSON 不會套用。

## 檔名規則

輸出名稱跟隨 HKDSE 穩定題目識別碼：

- M1／M2：2012AQ01_q.png、2012AQ01_a.png
- P1／P2：2012Q01_q.png、2012Q01_a.png
- 英文題目及答案會在內容 suffix 加上 _en，例如 2012AQ01_q_en.png。

介面容許改名，但檔名必須保持唯一，並只使用英文字母、數字、句點、底線及連字號。ZIP 內另有 manifest.csv，記錄卷別、年份、語言、內容、題目 ID、部份及界線。

## 輸出前檢查

只有以下檢查全部通過才會啟用輸出：

- 已載入 PDF。
- 題目表已建立。
- 每題起點及終點都是有效頁碼及 0 至 100 的百分比。
- 起點在終點之前。
- 各題範圍沒有重疊。
- 檔名符合格式及沒有重複。
- 左裁切位置小於右裁切位置，兩者均在 0% 至 100% 之內。

## 不在本階段的功能

- 不把題目及評卷參考界線放進同一範本或一套過輸出。
- 不在本機自動建議題目界線；界線仍由使用者確認。
- 不連接 Drive、不取得 file ID、不寫入 HKDSE 主表或 DSE OCR 審批分頁。
- 不進行正式 OCR；亦不處理 SVG。
- 不自動判斷題目界線、課題分類、分數或答案。

## 依賴及私隱

介面使用 repo 內鎖定的 PDF.js 及 JSZip 本機副本。PDF 內容在瀏覽器記憶體內讀取及渲染；下載「HKDSE 試卷逐題切圖工具」離線 ZIP 並完整解壓後，可直接以 `file://` 開啟。

工具只會產生使用者主動下載的圖片、ZIP 及 manifest，不會自動下載檔案或修改原 PDF。範本只有在使用者按「儲存到此瀏覽器」時才寫入指定的本機儲存鍵；manifest 亦會記錄左右裁切位置。
