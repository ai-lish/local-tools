# HKDSE Split Question

瀏覽器內的 HKDSE PDF 逐題切圖工具。把一份試卷 PDF 拖入頁面，逐題確認起點及終點，再輸出穩定命名的 PNG 或 JPG。檔案只在目前瀏覽器處理，不會上載到 Google Drive、GAS 或其他伺服器。

## 階段一範圍

- 拖放或選取 PDF。
- 顯示 PDF 頁面縮圖及目前頁面預覽。
- 按題數建立題目表。
- 以頁碼及頁面高度百分比設定每題的起點及終點。
- 支援跨頁題目；跨頁範圍會上下拼接為一張長圖。
- 每題可直接修改輸出檔名。
- 產生逐題圖片及 manifest.csv，或打包成 ZIP。

題目界線目前由使用者確認，工具不會自行猜測題號、課題、分數或甲乙部內容。M1、M2、P1 可以先用初始部份值，再在題目表逐題核對；P2 不顯示部份欄。

## 使用方法

1. 在 local-tools 根目錄啟動本機靜態伺服器：

       python3 -m http.server 8765

2. 開啟 http://127.0.0.1:8765/tools/hkdse-question-split/。
3. 拖入一份 PDF。
4. 選擇卷別、年份、語言及內容類型。
5. 輸入該份 PDF 的實際題數，按「建立題目表」。
6. 選取一行，按「設定起點」或「設定終點」，再在右側頁面按一下；亦可以直接編輯頁碼及百分比。
7. 核對每一行顯示為可輸出的狀態，按「下載逐題 ZIP」。

頁面高度百分比以 PDF 頁面的頂部為 0、底部為 100。起點及終點可以位於不同頁，適合卷一乙部的跨頁長題。

## 檔名規則

輸出名稱跟隨 HKDSE 穩定題目識別碼：

- M1／M2：2012AQ01_q.png、2012AQ01_a.png
- P1／P2：2012Q01_q.png、2012Q01_a.png
- 英文題目及答案會在內容 suffix 加上 _en，例如 2012AQ01_q_en.png。

介面容許改名，但檔名必須保持唯一，並只使用英文字母、數字、句點、底線及連字號。ZIP 內另有 manifest.csv，記錄卷別、年份、語言、內容、題目 ID、部份及界線。

## 輸出前檢查

只有以下檢查全部通過才會啟用輸出：

- 已載入 PDF。
- 題目表已建立。
- 每題起點及終點都是有效頁碼及 0 至 100 的百分比。
- 起點在終點之前。
- 各題範圍沒有重疊。
- 檔名符合格式及沒有重複。

## 不在本階段的功能

- 不連接 Drive，不取得 file ID。
- 不寫入 HKDSE 主表或 DSE OCR 審批分頁。
- 不進行正式 OCR；亦不處理 SVG。
- 不自動判斷題目界線、課題分類、分數或答案。

## 依賴及私隱

介面使用固定版本的 PDF.js 及 JSZip CDN。PDF 內容在瀏覽器記憶體內讀取及渲染；如 CDN 未能載入，工具會提示檢查網絡連線。暫時沒有把依賴內嵌，因此不應把目前頁面當作完全離線版本。

工具只會產生使用者主動下載的圖片、ZIP 及 manifest，不會自動儲存檔案或修改原 PDF。
