# 批改 PDF

瀏覽器本機工具，提供選擇題答題紙讀圈覆核及默書點擊批改。PDF 位元只由瀏覽器讀取和處理；工具不會上載 PDF 或呼叫 API。自訂範本及已選範本偏好會保存在這部電腦的瀏覽器；學生資料、答案、批改進度及任何金鑰不會寫入瀏覽器持久儲存。批改進度由用家下載／載入 JSON 檔；檔案不含原始 PDF 或學生姓名。

## 三步流程及範本

1. **選範本**：選擇「本校多項選擇題答題紙」或「本校金句默書紙」。其他版式可按 JSON schema 匯入自訂範本；範本驗證會以繁體中文列出錯誤及相容性提示。可匯出及刪除自訂範本，內置範本不可刪改。範本只儲存圈格／版面設定，不含答案或學生資料。
2. **載入 PDF 及答案**：只選本機 PDF；選擇題輸入題數、答案和每題分數，默書輸入所選段落句子。版式由範本決定。
3. **批改及匯出**：選擇題可跨頁逐題覆核，放大圈格後以按鈕或鍵盤修改並確認；默書按所選段落點擊格位。完成後可下載已批改 PDF、CSV 及進度 JSON。

「試玩示範」會在瀏覽器即時建立三頁合成答題紙，包含淡圈、雙圈及空白案例，並使用正式讀圈及覆核流程；示範匯出檔名會加上 `demo-`。不會把示範 PDF 作為檔案放入 repo。

## 開啟

在 repo 根目錄執行靜態檔案伺服器，然後瀏覽 `http://127.0.0.1:8000/tools/pdf-marking/`：

```sh
python3 -m http.server 8000
```

靜態伺服器只提供頁面及程式檔，沒有上載路由。PDF.js 3.11.174 及 pdf-lib 1.17.1 使用 repo 內鎖定的本機副本；下載「PDF 閱卷及批改工具」離線 ZIP 並完整解壓後，也可直接以 `file://` 開啟。PDF 只會交給本機頁面內的程式處理。

## 選擇題答題紙

1. 輸入選擇題及是非題題數、答案串和每題分數。每題分數留空或只填一個數值時會套用到所有該類題目；也可逐題以逗號分隔。
2. 選擇本機答題紙 PDF，按「自動讀圈／重新讀取」。目前模板對應直向顯示、三欄 60 題 A–D 及右側 10 題 T/F 的學校標準答題紙；兩類題數均可設為 0，未指定時仍預設 60 題及 10 題。頁面旋轉由 pdf.js 轉正。
3. 每頁先按五題一組的印刷間距估計平移、縮放和輕微旋轉，再以圈中心作細校正；班別和兩位學號區會按各自的圈格另作位置校正。讀取圈內填色深度後，每題四圈互相比較，並用本頁讀數分布調整分界。空白會列作空白；差距細、填色偏淡及多個深圈會留待覆核。若定位校正超出範圍或多數題目同時偵測到多個深圈，會改成單一整頁警告。班別及兩位學號讀不清時可在欄位手動修正。
4. 待覆核題目會列在側欄；在答題紙上點選／取消各圈可手動改答案，分數隨即更新。答題紙其他版式或嚴重偏移的掃描不在此模板範圍內。
5. 可下載帶紅色錯誤記號及頁面得分的 PDF、UTF-8 BOM CSV，以及不含 PDF／姓名的進度 JSON。CSV 包含頁碼、班別、學號、分數及每題作答／對錯。

選擇題讀圈只是一個覆核起點；未覆核前不可把低信心讀數當成已確認答案。現有定位依賴題組間距；採用均勻行距的自訂版式會顯示相容性警告，使用前須逐題檢查。此工具不辨識姓名。

## 默書

移植原 GAS 版的格位、點擊標記、計分及匯出行為；GAS 專案保持不變。

- 預設 33 格，按 20+13 排列；第一行格數可按 GAS 原設定調整。
- 每頁有兩段金句；每次選「第一段」或「第二段」（預設第一段），輸入該段答案後才批改。兩段的標記分開保留；進度 JSON 會記下所選段落及兩段的本機進度。
- 三種標記各自切換：紅圈、向上箭嘴、漏字紅⇄黑。
- `，、。` 不可標紅圈或漏字；向上箭嘴仍可用於標點。
- `N = |circles ∪ miss|`；`分數 = max(0, min(10, 10 − 0.5N))`，並四捨五入至 0.5。箭嘴不計入 N。
- 格線按所選段落位置的印刷橫線、直線及灰色停用格定位，不使用答案字數挑格；可定位不同段落的兩行或多行格表。答案只映射到可用格的前 N 格；答案字數與格數不符時會提示核對。畫面覆核與 PDF 匯出共用同一段落格線及佈局函式。無法確認格線時回退每行 20 格的預設模板，可再用滑桿微調。
- 按頁面 rotation 轉正；匯出只批改所選段落，並在該段的分數欄及改正線附近畫分數／改正句。分數文字會在欄內尋找較空的位置，避免蓋住已有筆跡。標記按原始頁面 rotation 放回正確位置。學號欄可留空，不做手寫辨識。
- 保留 GAS 左右／上下位移、縮放與重置校準；校準位置會用於畫面標記及 PDF 匯出，並存入進度 JSON。
- CSV 包含頁碼、班別（空白）、學號、分數及「段落」；進度 JSON 不含原 PDF 或姓名。

## 本機測試

```sh
node --test tools/pdf-marking/tests/*.test.cjs
```

測試用程式生成的合成答題紙圖像，不含真實學生資料。使用其他版本答題紙前，應先確認圈格位置，並逐頁覆核自動結果。

進度 JSON 使用版本 3；仍可載入版本 1 及 2。版本 3 記錄範本 ID；載入自訂範本進度前，須先在同一瀏覽器匯入該範本 JSON。

## 私隱與範圍

- 不使用任何 API；PDF、答案、姓名及分數不會送出瀏覽器。
- 瀏覽器本機儲存只用兩個白名單項目保存自訂範本及已選範本 ID；不會保存學生資料、答案、批改進度或金鑰。
- 進度 JSON 只由用家明確下載／載入，資料包括答案、班別、可選學號及標記狀態，但沒有姓名或 PDF 內容。請按需要妥善保管進度檔。
- 本階段沒有 API 入口、AI 核對或範本編輯器；範本以 JSON 匯入／匯出。
- 不把真實答卷或樣本放進 repo。根目錄 `.gitignore` 會忽略樣本目錄、PDF、PNG 及 CSV。
- `tool.yaml` 目前標記為 `wip`；模板精度及各校答題紙相容性需依實際使用前覆核。
