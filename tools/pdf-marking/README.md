# 批改 PDF

## 公開摘要

在瀏覽器批改掃描答題紙：選擇題自動讀圈，默書點擊批改。

- 適用對象：需要批改選擇題答題紙或默書的老師。
- 開始：在首頁按「開始批改」，選擇或匯入範本，再設定答案；如需新範本，可另開樣本建立流程。
- 主要功能：拉框或點圈建立範本、本機自動對位、讀取標準答案、自動讀圈及逐題覆核、成績查詢，以及匯出 CSV、Excel 及已批改 PDF。
- 整份 PDF 及成績不會上載；AI 覆核預設關閉，老師輸入 API key 並確認後，才會把所需的去識別裁切圖傳往所選 AI 服務。
- 學校網絡擋網站時，可在下載頁下載離線 ZIP（只做選擇題可用 `pdf-marking-choice.zip`），解壓後直接開啟。
- 讀圈結果只是覆核起點，待覆核題目及班別學號須由老師確認。

## 說明

瀏覽器本機工具，提供選擇題答題紙讀圈覆核、默書點擊批改及選用 AI 覆核。PDF 會在瀏覽器本機讀取和處理；只有用家明確輸入 API key、啟用 AI 並確認送出後，才會把通過身份區硬性檢查的裁切圖傳往 Gemini 或 MiniMax。瀏覽器只保存選擇題自訂範本、已選範本偏好及 Google Drive 同步設定，鍵名固定為 `pdf-marking.templates.v1`、`pdf-marking.preferences.v1` 及 `pdf-marking.drive-sync.v1`；沒有使用無前綴的儲存鍵。學生資料、答案、批改進度及 API key 不會寫入瀏覽器持久儲存。批改進度由用家下載／載入 JSON 檔；檔案不含原始 PDF 或學生姓名。選擇題自訂範本可由老師按鈕手動同步到 Google Drive；不會自動同步。

首頁的「清除本機資料」只會刪除上述三個 `pdf-marking.` 鍵，並以重新載入頁面清空記憶體中的 API key、PDF、答案及讀圈結果；其他 Local Tools 工具的儲存資料不受影響。清除前會在頁面內列明項目並要求確認。PDF、答案及成績本來就不會儲存；已下載的檔案不受影響。若瀏覽器禁止本機儲存，頁面會顯示未能完全清除的提示。

## 四步選擇題流程及範本

首頁以「開始批改」進入範本選擇。選擇題主流程分為四步；默書仍沿用原有批改流程。首頁另有換範本、成績查詢及建立範本入口。「更多」保留合成示範；範本清單的「更多範本功能」提供編輯、匯出及刪除。

1. **範本**：選擇最近使用或其他範本，亦可匯入範本 JSON。若要新建或以範本副本開始，按「建立範本」進入獨立的樣本設定及位置編輯流程；完成並儲存後回到答案步驟。Drive 同步入口標示為「Google Drive 同步」。
2. **答案**：可在題號格直接選答案，或整批輸入；兩者會雙向同步。選擇題及是非題題數可在本步按今次試卷調整，設為 0 會隱藏該類答案欄；減少題數不會刪除輸入尾段，之後增加題數可恢復使用。未設定題目會清楚列出。匯入範本後會直接到這一步，無須載入樣本。由標準答案卷及評卷參考讀取等其他答案來源收在本步的展開項目。
3. **覆核及輸入**：選擇全班 PDF 後會自動讀圈。左側分開列出整頁定位失敗、待覆核題目及班別／學號待確認頁；可逐題覆核，或切換「表格輸入」直接修改答案。表格支援選項字母、空白、方向鍵、Tab、Enter、TSV 貼上及最近 20 次復原。整頁定位失敗頁的所有答案都填入或確認後才計分。診斷、AI 覆核及其他警告收在「更多」。
4. **匯出**：頂部顯示已確認頁數、尚欠學號及老師修改題數；未處理項目可點選返回覆核。可輸入全班人數及複製按學號排列的作答；Excel、CSV、已批改 PDF、進度 JSON 及成績預覽沿用現有格式。現時沒有「複製分數（按學號）」功能，因此保留「複製全表」作為分數表複製方式。

建立範本時可載入一頁本機答題紙 PDF，指定頁碼，再選「由零建立」或「由現有範本開始」。在樣本頁拖拉文字遮罩（姓名、科目或其他）、班別／班號圈格或手寫遮罩，以及一個或多個選擇題／是非題答案欄；各框可移動、調整大小或刪除。文字區只存為遮罩，不會 OCR。手寫班別及班號會留待老師確認。答案欄亦可用「點圈建立答案欄」：點選第一題各選項圈及另一題的圈，程式按量得的選項間距及行距排出其餘題目，可再量度組間空位或「再加一欄（同樣間距）」。樣本只在記憶體處理，不會上載、儲存或寫入範本。
   - 可選 AI 版面建議沿用下方同一組供應者、模型及只存於記憶體的 API key。開始前必須標示所有身份區並確認，或明確聲明沒有身份區。送出前會顯示實際預覽、供應者及遮罩區；只按「確認送出」才會傳送。新畫布會把身份區連同至少 1.5% 頁寬的安全邊距塗黑，並逐像素核對；每次只傳一張長邊不超過 1600 像素的影像。AI 只回傳圈格位置、欄別選項、題數及題號排列，不會要求轉錄文字。建議須逐項接受，之後仍可移動、改大小或刪除；未接受的建議不會自動存入範本。取消不會送出。本機找圈可用「點圈建立答案欄」及第三步的「本機自動對位」。
3. **設定題數及位置**：每個答案欄可設定題數；可選按欄或按行編號。沿用範本編輯器拖拉圈位、調整間距及行距，以樣本測試讀圈，然後按「儲存到此瀏覽器」或「匯出範本 JSON（下次使用）」。
   - 檢視可切換「整頁」「闊度」「放大所選組」；控制列在捲動時固定於頂部。
   - 選取一組後，拖該組最後一行的手柄改行距（第一行固定），拖第一行的手柄移動整組；疊圖取得焦點時，Alt＋↑／↓ 調行距、Alt＋←／→ 調選項間距，加 Shift 步幅較大。
   - 勾選「全部選擇題組同時套用行距」，或按「把所選組的行距套用到全部組」，可統一多組選擇題的行距；每組以自己的第一行為固定點，任何一組超出頁面時整個操作不套用，一次撤銷即可還原。
   - 「本機自動對位」在樣本頁附近搜尋圈心，先顯示調整前後預覽，按「套用」才修改草稿，並自動以樣本測試讀圈；一次撤銷即可還原。
   - 「以樣本測試讀圈」會顯示定位診斷疊圖：預計及讀取圈心、各組平均偏移（mm）；偏移超過圈半徑一半以橙色、超過一個半徑以紅色標示，組間空位如偵測到墨水亦會列出。範本欄序與題號次序不符時，第二步會提示並提供「重新排列欄序」。內置範本會先建立副本。範本只存座標、題型、各欄選項及遮罩設定，不含樣本、答案或 AI 回應。
4. **設定答案**：可在樣本頁點擊每題圈格設定或取消答案；每題只可選一個選項。未設定題目會清楚列出。亦可整批輸入，並與圈格點選雙向同步；答案不會寫入範本。
   - 「由標準答案卷讀取」：以一張填好標準答案的答題紙（可為批改 PDF 其中一頁）在本機讀圈；讀不清的題目標示「待老師設定」，不會自動填入。答案卷與學生卷在同一份 PDF 時，勾選「此頁為答案卷」，該頁不計分、不入待覆核、不匯出。
   - 「由考卷或評卷參考讀取」：載入後會掃描整份 PDF 的文字層，沿用答案表、逐行及橫向表格解析。文字解析配對數達到第 2 步設定題數時直接採用；未達時亦會在本機分析螢光，採用有效答案較多的來源；相同時保留文字解析結果。題號須在頁面左側 9% 範圍內，同一行被 PDF 拆開的題號片段會合併。頁首 6% 內只接受接續上一題的題號（第一個題號可為 1），其他頁首數字略過；其他位置接受接續上一題或 1。新序列由 1 開始時會清除前一段的分析結果；同一序列內真正重複的題號留作「待老師設定」。每題只有一個標示選項才會讀取；沒有或多於一個標示會留作「待老師設定」，不會猜答案。黃色按 `R>200、G>200、B<120` 判斷；綠、粉紅及淺藍使用亮度與飽和度門檻（最大 RGB 至少 150、最小值至少 45、色差至少 38，且色差／最大值至少 0.18）；選項取樣區超過 20% 符合才算標示。題數不符時會提示，答案仍須核對並按「套用答案」。文字及螢光均沒有讀到答案時，才顯示 AI 選項；掃描本仍可使用 AI，送出前須預覽、遮罩並按「確認送出」。
   - 兩種方法都先顯示答案表，老師核對並按「套用」才會寫入。
5. **批改及匯出**：輸入實際批改 PDF 後使用自動讀圈、逐題覆核及 AI 覆核選項。可檢查成績預覽、複製 TSV 到 Excel、下載 XLSX、已批改 PDF、CSV 及進度 JSON。批改頁面提供逐題和表格兩種輸入方式，兩者寫入同一份現有進度資料。
   - 整頁定位失敗時會列出原因；可選「逐題確認」重新讀取、「表格輸入」跳到該頁答案列，或開啟範本編輯器並以該 PDF 作樣本。逐題確認後，該頁所有題目均確認前不計分。
   - 「成績查詢」由首頁進入獨立畫面；可載入原 PDF 及進度檔，再按班別、學號（或直接選頁碼）找出頁面。畫面顯示總分、題組小計及作答狀態篩選；題目截圖會從原 PDF 在本機重繪，標準答案以綠框標示。截圖不寫入進度檔或任何匯出。

自訂範本可匯入、匯出及刪除；範本驗證會以繁體中文列出錯誤及相容性提示。範本格式沿用版本 1；新增的每欄行位、每欄選項及手寫身份欄位屬可選欄位，舊範本仍沿用原有共用行位及圈格行為。

### Google Drive 範本同步（線上版）

同步只涵蓋自訂選擇題範本 JSON。只有按「上載範本到 Drive」或「由 Drive 下載範本」才會連線；範本放在名為「Local Tools 範本」的 Drive 資料夾。相同 ID、內容不同時會列出差異及較新版本建議，由老師選擇保留哪一版；未經選擇不會覆寫本機範本。無效或不相符的 JSON 會略過並列明原因。

首次設定 OAuth 用戶端 ID：

1. 在 Google Cloud Console 建立或選用 Google Cloud 專案，啟用 Google Drive API。
2. 設定 OAuth 同意畫面；測試期間可選測試模式，並把需要使用的老師帳戶加入測試使用者。
3. 建立「網頁應用程式」OAuth 用戶端，於「已授權的 JavaScript 來源」加入 `https://ai-lish.github.io`。
4. 把網頁用戶端 ID 貼到工具的設定欄並保存。用戶端 ID 是公開識別碼，不是密碼；不要放入 client secret。

如沿用 AI-Learning 現有 Firebase／Google Cloud 專案，請在該專案啟用 Google Drive API，使用該專案自動建立的 Web 用戶端 ID，並在其已授權 JavaScript 來源加入 `https://ai-lish.github.io`。程式使用 Google Identity Services 和 `drive.file` 範圍，不引入 Firebase SDK，也不使用 Firestore 或 Firebase Auth。Drive API 呼叫不需要 API key；若專案 API key 設有 API 限制，毋須為本功能放寬該 key。

登入後的存取 token 只在目前頁面記憶體中使用，重整頁面即失效；不寫入瀏覽器儲存、檔案或記錄。瀏覽器只會保存公開用戶端 ID、上次同步時間及範本對應資料。離線 ZIP 不載入 Google 腳本，並顯示「離線版不支援雲端同步」。

「試玩示範」會在瀏覽器即時建立三頁合成答題紙，包含淡圈、雙圈及空白案例，並使用正式讀圈及覆核流程；示範匯出檔名會加上 `demo-`。不會把示範 PDF 作為檔案放入 repo。

## 開啟

在 repo 根目錄執行靜態檔案伺服器，然後瀏覽 `http://127.0.0.1:8000/tools/pdf-marking/`：

```sh
python3 -m http.server 8000
```

靜態伺服器只提供頁面及程式檔，沒有上載路由。PDF.js 3.11.174、pdf-lib 1.17.1 及 JSZip 3.10.1 使用 repo 內鎖定的本機副本；下載「PDF 閱卷及批改工具」離線 ZIP 並完整解壓後，也可直接以 `file://` 開啟。預設不需網絡；選用 AI 覆核時才連接相應 API。

## 選擇題專用離線包

`pdf-marking-choice.zip` 只提供選擇題流程，解壓後顯示選擇題首頁；不顯示默書入口、控制項或示範。範本建立及匯入、AI 建議版面、讀圈、CSV／XLSX／PDF 匯出和進度檔仍可使用。完整版 `pdf-marking.zip` 及 `core-all.zip` 仍保留默書入口及功能。

選擇題專用包保留 `app.js`、`model.js`、`geometry.js`、`pdf-export.js`、`demo.js` 等共用模組，因它們同時支援選擇題與默書流程；只在離線建置結果隱藏默書入口並直接開啟選擇題流程，沒有把共用程式拆分或重構。

## 選擇題答題紙

1. 以樣本建立範本或匯入範本，再在第二步設定題數及答案；範本圈位數不足時會提示減少題數或調整位置。每題分數留空或只填一個數值時會套用到所有該類題目；也可逐題以逗號分隔。
2. 第三步按「選擇全班 PDF」載入本機實際答題紙；工具會自動開始讀圈。頁面旋轉由 pdf.js 轉正；手寫身份欄必須由老師輸入並確認。需要更換檔案時按頂部檔名。
3. 每頁先按五題一組的印刷間距估計平移、縮放和輕微旋轉，再以圈中心作細校正；圈格身份欄會按其座標另作校正。讀取圈內填色深度後，每題選項互相比較，並用本頁讀數分布調整分界。空白會列作空白；差距細、填色偏淡及多個深圈會留待覆核。若定位校正超出範圍或多數題目同時偵測到多個深圈，會改成單一整頁警告。手寫班別及班號讀不清時可在待處理的「學號」組確認。
4. 預設逐題覆核；也可切換「表格輸入」，用答案字母或空白修改答案，貼上 Excel／Google Sheets 的 TSV 區塊。表格的分數即時更新；整頁定位失敗頁的所有題目填入或確認後才計分。逐題瀏覽及答題紙直接點圈修改仍可使用。
5. 可下載帶紅色錯誤記號及頁面得分的 PDF、UTF-8 BOM CSV，以及不含 PDF／姓名的進度 JSON。匯出頁會顯示完成頁數、尚欠學號及老師修改題數；成績查詢可在首頁獨立進入，按題組及狀態查閱同一份原 PDF 的題目截圖。
逐題覆核的「本頁中位數」及每個選項填色百分比只供老師判斷；題組小計和篩選不會改變讀圈、答案、計分或匯出資料。

## 成績預覽及 Excel

- 第四步可展開「成績預覽」，顯示與 CSV 相同的資料欄及列；預設按班別、學號排序，也可切換按頁碼。每列頁碼旁會以文字標明分數留空、待覆核、人手調整或班別／學號未確認；點擊該列可跳到相應頁面。提示只供畫面核對，不會加入匯出資料。
- 「複製全表」會連表頭一併複製目前排序的 TSV。若瀏覽器不允許剪貼簿存取，工具會顯示已選取的唯讀文字框，供手動複製。
- 選擇題模式另有「複製作答（按學號）」：輸入全班人數後，按學號 1 至指定人數排列，每題一欄；未作答填 `X`，沒有答題紙的學號保留空白列。重複學號會阻止複製；未確認身分、待覆核或超出人數設定的頁面會先列出並要求確認。
- 「匯出 Excel（.xlsx）」會以本機 JSZip 建立單一工作表，凍結首列；數字欄按數值儲存，學號等文字保留字串格式及前導零。TSV 及 XLSX 的文字欄位會清除 Tab／換行，並在 `= + - @` 開首的內容前加 `'`，避免被試算表當成公式。

選擇題讀圈只是一個覆核起點；未覆核前不可把低信心讀數當成已確認答案。現有定位依賴題組間距；採用均勻行距的自訂版式會顯示相容性警告，使用前須逐題檢查。此工具不辨識姓名。

## 默書

- 預設使用「答案句標記」；老師可在第三步切換段落、修改完整答案句及選擇「舊版格位模式」。第二段如未填答案，會保持空白，不會沿用第一段。
- 新模式在 PDF 頁面任何位置放置紅色錯字圈、紅色多字圈或上箭嘴；角標只在畫面區分「錯／多」，PDF 不畫角標。再點同一位置的同類標記可移除，並可撤銷上一步。錯字圈及箭嘴只作標示；多字圈數目才計入「多字」。
- 答案句會移除首尾及句內空白、換行，以 Unicode code point 計字。常見中英文標點自動識別、不計字且不可點擊。點擊非標點字會循環切換「正常 → 錯字 → 漏字 → 正常」；錯字及漏字均以紅色顯示，漏字另有小標示。
- 新模式計分：`N = 錯字 + max(多字, 漏字)`；`原始分 = max(0, 10 − 0.5 × N)`，結果至 0.5 分。錯字及漏字按答案句計數。可選底分預設關閉；正確字數為「答案字數 − 錯字 − 漏字」，至少 5 字底分 2 分、至少 10 字底分 3 分，最終分不低於底分。
- 每頁初始為「未批改」，分數留空；首次點擊卷面標記或答案字會自動標為「已批改」。也可按「已批改（全對）」。PDF 匯出前會列出未批改頁碼並要求確認；CSV 會保留未批改列並將分數欄留空，不會填上 10 分。
- 新舊模式均可人手覆寫錯字、多字、漏字、最終分及每頁底分設定；頁面和 CSV 會標示「人手調整」，CSV 同時保留自動最終分。可按「還原自動計算」。
- 舊版格位模式保留 GAS 移植版的格線標記和原自動計分；標點改由句子自動更新。它仍按印刷格線定位；無法定位時使用後備每行格數 20 格，可用滑桿校準。後備格數可調整，不代表印刷第一行格數。
- PDF 會在原有分數欄及改正線附近畫分數和完整答案句；錯字、漏字為紅色，其他字為黑色。分數欄沿用避開筆跡的定位方式。卷面標記只畫一次，並按頁面 rotation 0／90／180／270 放回正確位置。未批改頁不畫分數。
- 默書 CSV 欄位為頁碼、段落、學號、狀態、錯字、多字、漏字、N、正確字數、底分開關、底分、原始分、自動最終分、最終分及人手調整；保留 UTF-8 BOM 和 CRLF。以公式字元開首的欄位會加 `'`，Tab 和換行會清除。
- 進度 JSON 升為版本 4，包含兩段的每頁卷面標記、答案字狀態、頁面狀態、底分及人手覆寫，不含 PDF 或姓名。載入舊版 v1／v2／v3 會把圈及漏字轉到答案句，把箭嘴放回卷面位置，並提示核對；無效或超範圍資料會報告丟棄數目。

## 私隱與範圍

- AI 覆核預設關閉。送出前會顯示供應者及影像，並要求確認；版面建議另會顯示已遮走的身份區，先以新畫布遮罩再逐像素確認，長邊不超過 1600 像素。姓名一律遮擋；新建範本的手寫班別及班號預設不遮擋，可按範本需要選擇遮擋。舊範本已設定遮擋時會保留。選擇題只送待覆核題圈格列；默書只送目前段落的作答帶，不含頁首；每次要求一頁一張、圖片長邊不超過 1024 像素。未經確認不會呼叫 API。
- 選擇題答案覆核只包含圈格選項判讀，不附答案鍵；版面建議只接受座標、題型、選項標籤、題數及排列方式，不接受轉錄文字或解釋；默書只要求轉錄手寫文字，不傳答案句。AI 結果留在本頁記憶體，重整頁面即清除；只在老師逐項接受後才把版面建議放到可編輯範本區，仍須老師保存範本。
- API key 只放在記憶體及請求驗證標頭，不在網址、進度 JSON、CSV、PDF、範本或 console 中；「清除 key」會清空輸入。不要在共用或不受信任的瀏覽器環境輸入 key。
- 選用 AI 時會把去識別裁切圖交給所選服務處理；請先確認符合學校及服務供應者的資料政策。未使用 AI 時，PDF、答案、姓名及分數不會送出瀏覽器。
- 瀏覽器本機儲存以白名單鍵保存自訂範本、已選範本 ID，以及公開用戶端 ID和範本同步對應資料；不會保存學生資料、答案、批改進度、API key 或 access token。
- 視覺編輯器所選樣本 PDF 只在頁面記憶體中顯示及測試，離開編輯器後即清除；樣本不會上載、保存或放入範本 JSON。
- 進度 JSON 只由用家明確下載／載入，資料包括答案、班別、可選學號及標記狀態，但沒有姓名或 PDF 內容。請按需要妥善保管進度檔。
- 僅支援選擇題範本視覺編輯，默書範本編輯仍不在範圍內。AI 回覆可能有誤，老師須逐項核對；批次限制為同時最多兩個請求，網絡錯誤不會自動重試。
- 不把真實答卷或樣本放進 repo。根目錄 `.gitignore` 會忽略樣本目錄、PDF、PNG 及 CSV。
- `tool.yaml` 目前標記為 `wip`；模板精度及各校答題紙相容性需依實際使用前覆核。
