R-ASR024 操行等級計算器

按四科操行等級計算平均結果，整理班別及班號，方便核對後貼回 Excel。貼上前請先設定欄位與各班人數。

檔案及貼上的資料只在本機處理，不會上載或發出網絡請求。

1. 欄位設定

預設欄序為原操行、班主任、中文、英文、數學。首列如沒有任何有效等級，會視作表頭並略過。匯入後如要轉換欄數，請先匯出或清空現有列。

2. 班別及學生人數

列會按班別清單次序及人數分配；人數只用作預覽及分班，不會自動刪除或補造資料。

3. 貼上及預覽

只以 Tab 分欄；沒有 Tab 時才以逗號分欄。中間空列會保留，只有結尾全空列會移除。

五欄格式例：原操行　班主任　中文　英文　數學（每列一名學生；請按上方欄位設定調整）

    計算法

    先找出四科最低等級，再計算四科相對於最低等級的平均級距，按所選取整方式調整，最後加回最低等級；結果最高為甲級。

    等級：丁 = 0，丙− = 1，丙 = 2，丙+ = 3，乙− = 4，乙 = 5，乙+ = 6，甲− = 7，甲 = 8。
    此法結果與「四科直接平均後按同一規則取整」相同；分值設定只影響顯示。
