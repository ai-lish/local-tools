# R-ASR024 操行等級計算器

以瀏覽器本機整理 CloudSAMS R-ASR024 報告的操行等級。工具不連接 CloudSAMS、不上載資料，也不發出網絡請求。

## 用法

1. 輸入每班學生人數，並按需要更改班名、次序或欄位對應。
2. 選擇 5 欄（原操行、班主任、中文、英文、數學）或 4 欄（四科）。可以修改每欄代表的科目。
3. 從 Excel 複製資料貼到文字框。以 Tab 分欄；沒有 Tab 時才以逗號分欄。空白欄位會保留。只有結尾全空列會移除；中間的空列和格式錯誤列會保留並標示原因。
4. 預覽列數、各班首尾列和問題列。列數與班額不一致時會提示，仍可自行決定是否套用。
5. 核對結果；可以修改原操行或科目、增加或刪除列，並按班別篩選。複製結果可貼回 Excel；CSV 匯出會包括班別、班號、原始欄位、計算結果及狀態。

## 計算法

等級以丁 = 0、丙− = 1、丙 = 2、丙+ = 3、乙− = 4、乙 = 5、乙+ = 6、甲− = 7、甲 = 8 對應數值。先取四科最低等級，再計算四科相對最低等級的平均級距，依四種取整模式調整後加回最低等級。此法結果與四科直接平均後按同一規則取整相同；每級分值設定只影響分值顯示。請依學校採用的取整方式設定並核對結果。

## 限制

- 工具不會自動辨認貼上內容內的班別；請先設定班別次序及人數，資料列會按次序分班。
- 貼上資料須每列一人。欄數不符、科目缺漏或等級無效的列不會計算，但會保留在預覽、表格和輸出中。
- 匯入後欄數及欄位對應會鎖定，以免同一批列使用不同格式；如要改用另一格式，請先匯出或清空現有列。
- 「重設預設資料」載入的是虛構示範，不是學生紀錄；「清空資料列」可移除畫面上的列。
- 本機瀏覽器記憶體有限；特大範圍請分批處理。工具不會把資料保存到瀏覽器的永久儲存位置。
- 「下載空白工具 HTML」會下載初始化時的空白頁面，不包含目前貼上的資料。

## 私隱

貼上的資料和結果只在本機瀏覽器記憶體處理。工具沒有網絡依賴，不會連接 CloudSAMS，也不會上載資料。匯出檔案由使用者明確操作後才會下載到本機。
