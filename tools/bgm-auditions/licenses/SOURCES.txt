Offline renderer: TinySoundFont by Bernhard Schelling; MIT license; full text in TinySoundFont-LICENSE.txt.

Narration: an existing mathematics-video dry voice, reused without a new text-to-speech request. This directory does not grant any separate right in a third-party voice service.

General MIDI presets: 0 acoustic grand piano; 4 electric piano 1; 24 nylon guitar; 89 warm pad; 4 electric piano 1 with the standard GM drum bank; 11 vibraphone.

The MP3 files in ../audio/ are the approved audition assets for this directory. Generation logs, local paths, the SoundFont binary, and intermediate caches are not published with this page. Checksums for the published MP3 files are in ASSET_SHA256.txt.

MiniMax-Music3 AI-generated auditions (ai01-ai07, ai_cmp_4bit, ai_cmp_allgpu): machine-generated on 2026-11-13 and 2026-11-15 HKT by the open-weight MiniMax-Music3 model (MiniMaxAI/MiniMax-Music3, revision 1b525ccb685ae809f33027c51c351eeb5833cf72), run locally on one PC with diffusers. No cloud API, no reference audio, no lyrics (the lyrics field was "[instrumental]"), and no named artist or existing song in the prompts. Model license: MiniMax-Music3 Community License, full text in MiniMax-Music3-LICENSE.txt. Its Acceptable Use Policy requires public machine-generated content to be clearly disclosed, which the page does.
Each file was requested as 30 seconds; the model may end a piece early, so the page lists the actual length of each file.
Quantization: ai01-ai07 and ai_cmp_allgpu use a 4-bit (NF4) language model with an 8-bit transformer, all on the GPU. ai_cmp_4bit uses the 4-bit language model with a BF16 transformer and CPU offload. The two comparison files are 10 seconds long and use the same prompt and seed.
Loudness: each AI file was normalised to about -23 LUFS integrated (measured -22.8 to -23.6 LUFS) with peaks at or below -1 dBFS, then encoded as 48 kHz stereo 192 kbps MP3. Prompts, seeds and generation logs are kept locally and not published.
