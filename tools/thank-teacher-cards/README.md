# 箋紙濃情謝師恩｜文章核對及卡片工具

在瀏覽器整理學生名單、謝師恩文章 OCR、老師修訂稿及感恩卡。頁面可配合不同班別使用，資料不會預載在公開網站。

## 使用前準備

先準備以下內容，再到「匯入內容清單」匯入：

1. **學生名單 CSV／JSON**：每列至少有「班別、班號」；可加入正式學號、中文／英文姓名、所屬小學、收件老師、應交張數和紙本已收張數。空白應交張數代表待核，`0` 或豁免欄才代表免交。
2. **文章 OCR**：貼上 Gemini、MiniMax 或其他 OCR 產生的文章文字／單頁 JSON；也可直接輸入 MiniMax API key、選取單頁影像進行 OCR。批次 OCR JSON 可用 `{"pages":[{"page":1,"class":"班別","classNumber":1,"studentName":"學生姓名","primarySchool":"所屬小學","teacherName":"老師姓名","ocrText":"文章文字","uncertainNotes":"疑字"}]}`；班別和班號要能明確對上名單，否則請逐頁選學生後貼入。
3. **Word 範本（可選）**：可使用內置範本，或上載校方 DOCX 範本。範本欄位包括 `{teacherDisplay}`、`{correctedText}`、`{studentName}`、`{studentNameEn}`、`{className}`、`{classNumber}`、`{studentNumber}`、`{primarySchool}` 和 `{activityTitle}`。

名冊收件規則：原名冊「2」欄剔號代表應交 2 張；其他剔號代表 1 張；「1」下方圈號代表免交。掃描頁數不等於紙本收件數。

## 本機資料與匯出／匯入

- 編輯內容會自動保存於目前瀏覽器的本機儲存區，不會送到 Local-tools 網站。
- **JSON 備份**包含學生記錄、文章、批改狀態、Word 範本及字體大小；重新匯入會先要求確認，並以備份完整取代該瀏覽器的現有記錄。
- **CSV 匯入**可合併名單或文章欄位；未列出的學生會保留。CSV 和文章資料可匯出作表格處理。
- 可逐名匯出 DOCX 感恩卡，亦可預覽卡面和 Word 主要版面、調整字體大小。
- 清除瀏覽器網站資料會刪除本機記錄；請定期下載 JSON 備份，並把備份放在學校核准的位置。

## OCR 私隱

MiniMax OCR 由瀏覽器直接連接 MiniMax API。只有按下「送 MiniMax OCR」後，所選 JPEG／PNG／WebP 影像和 API key 才會傳送至 MiniMax；key 不會寫入本機記錄、備份或公開檔案。每次限一張、5 MB 以內。請先遵守校方資料處理要求，只上載必須辨認的頁面，避免把無關的電話或聯絡資料送出。

也可使用外部 OCR，再把結果貼上工具。OCR 文字及身份仍需人工核實。老師修訂稿另欄保存；批改時檢查錯字、文句通順及格式，保留學生原意，不清楚處請學生確認。

## 批改與定稿流程

1. 匯入正式名單，核實班別、班號、學號、姓名和所屬小學。
2. 逐份點收紙本，分開記錄應交張數、已收張數和掃描頁數。
3. 匯入 OCR，核對姓名、老師及疑字，再修正「核對後 OCR」。
4. 在「老師修訂稿」檢查錯字、文句和格式，逐項標記批改狀態。
5. 預覽卡面及 Word，選擇字體大小，再匯出 DOCX，並在 Word 檢查實際分頁。

外部 Word 元件由固定版本 CDN 載入；如未載入，請檢查網絡連線後重新整理。
