# 箋紙濃情謝師恩｜文章核對及卡片工具

在瀏覽器整理學生名單、謝師恩文章 OCR、老師修訂稿及感恩卡。頁面可配合不同班別使用，資料不會預載在公開網站。

## 使用前準備

先準備以下內容，再到「匯入內容清單」匯入：

1. **學生名單 Excel／CSV／JSON**：可直接上載 `.xlsx` 或 `.xls`，工具會在目前瀏覽器讀取工作表，不會把 Excel 傳到網站；也支援 CSV／JSON。名冊標題列至少要有「班別、班號」，小學欄可用「所屬小學」、「所屬小學名稱」、「小學名稱」或「小學」。可加入正式學號、中文／英文姓名、收件老師、應交張數和紙本已收張數。空白應交張數代表待核，`0` 或豁免欄才代表免交。含有效名冊欄位的工作表會一併讀取；重複班別／班號會拒絕整份 Excel，避免覆蓋錯誤。
2. **文章 PDF／JPG／PNG**：第三步可一次選取多份 PDF、JPG 或 PNG；工具按選取次序把 PDF 頁面和圖片合併為逐頁工作區，並列出每頁來源檔名。總容量上限 100 MB、合計最多 300 頁。載入後在第三步配對表逐頁選學生並保存；配對數量會顯示為「已配對／總頁數」。工具不會根據頁序、OCR 姓名或其他欄位自行配對。
3. **文章 OCR**：第四步可選「縮圖總覽」或「逐頁檢視」，並用上一頁／下一頁翻頁。按「複製圖片交 Gemini」和「複製本頁 Gemini OCR 提示」，讓 Gemini 只抄錄圖片內容，輸出純 JSON。範例：`{"page":1,"className":"1A","classNumber":"1","studentName":"學生姓名","primarySchool":"所屬小學","teacherName":"收件老師","ocrText":"文章原文","uncertainNotes":["疑字"]}`。把逐頁結果貼回工具後，頁碼必須對應目前工作區。超過 2,800 字的單頁 OCR 會整批拒收並提示分段，不會靜默截短；已匯入頁重新貼入時會略過。OCR 身份只作核對候選，不會更改第三步配對；資料不一致會在匯入前提醒老師人工核實。確認原稿和配對後，按「匯入配對文章」，OCR 原文和單頁 PDF 會一同連到第三步指定的學生。
4. **替換初稿**：可在第四步整批替換 PDF／圖片；相同頁數會保留第三步配對，已匯入頁須重做 OCR 才能更新同一學生的原頁附件。也可拍照或選一頁檔案，只替換該頁。已匯入頁更新時保留老師修訂稿及核對後 OCR；若頁面附件無法唯一識別，工具會停止並引導到第五步以「更新內容」處理。
5. **Word 範本（可選）**：可使用內置範本，或上載校方 DOCX 範本。範本欄位包括 `{teacherDisplay}`、`{correctedText}`、`{studentName}`、`{studentNameEn}`、`{className}`、`{classNumber}`、`{studentNumber}`、`{primarySchool}` 和 `{activityTitle}`。
6. **彩色封面及內頁（第六步）**：上載封面和內頁 JPG／PNG／WebP，內頁會套用第五步採納的老師修訂稿及收件老師；Word DOCX 匯出只使用第五步採納的修訂稿；未採納前，OCR 只在預覽中標示為草稿，PNG 和雙面 PDF 不會使用它。列印文字超出卡面時會提示，且不會生成列印內容。第六步以內頁右頁預覽為主，可調字體大小、文字欄寬和文字區高度；預覽會估算行數及佔用比例，供老師判斷是否請學生增減內容。可切換封面／內頁、列印／儲存雙面 PDF，或下載／複製內頁 PNG 給學生抄寫。Word DOCX 是進階可選匯出。

名冊收件規則：原名冊「2」欄剔號代表應交 2 張；其他剔號代表 1 張；「1」下方圈號代表免交。掃描頁數不等於紙本收件數。

## 本機資料與匯出／匯入

- 編輯內容會自動保存於目前瀏覽器的本機儲存區，不會送到 Local-tools 網站。
- **JSON 文字備份**包含學生記錄、OCR、逐頁配對及批改狀態，不包含 PDF／色稿影像附件。
- **完整備份 ZIP**包含 JSON 記錄、Word 範本、目前逐頁工作區及記錄實際引用的 PDF／色稿影像附件；未引用附件不會打包。附件總容量上限為 190 MiB，匯出 ZIP 上限為 200 MiB。匯入會先要求確認，再以 ZIP 內容取代目前記錄並匯入附件。若需整理本機未引用附件，使用「檢查／清理未引用附件」；清理前會顯示數量並再次確認，建議先下載完整 ZIP。跨電腦或清理瀏覽器資料前請下載 ZIP。
- **Excel／CSV 匯入**可合併名單或文章欄位；未列出的學生會保留。Excel 小學欄匯入後會顯示已讀取的小學名稱列數和不同名稱數。CSV 和文章資料可匯出作表格處理。
- 學生編輯頁可用手機相機拍照或上載 PDF／JPG／PNG，選「補交」加入現行附件，或選「更新內容」令新檔成為現行版本並保留舊版本下載。每名學生頁面會顯示現行原稿圖片預覽；PDF 預覽顯示首頁，下載按鈕仍包含完整附件。附件和版本歷史保存在目前瀏覽器；更新現行掃描頁數不會代替紙本點收張數。
- 按班進度總表即時統計名冊人數、應交及已收張數、完成遞交人數、欠交張數、掃描頁數和老師批改完成數。完成遞交按紙本已收張數計算；免交學生不計入應交人數，待核張數及待點收人數會另行顯示。
- 第六步以彩色內頁右頁預覽為主，可調字體大小、文字欄寬和文字區高度，估算文章行數與佔位，協助判斷是否請學生增減內容；可下載／複製內頁 PNG 或列印雙面 PDF，DOCX 為進階可選匯出。
- 彩色封面／內頁色稿和學生掃描一樣只保存在目前瀏覽器，沒有放入公開網站檔案。圖片如含學生姓名或聯絡資料，不應直接複製到公開 repo。
- 清除瀏覽器網站資料會刪除本機記錄和掃描附件；請定期下載完整備份 ZIP，並把備份放在學校核准的位置。

## Google Drive 跨裝置備份

- **目前暫停**：Google Drive 上載、雲端備份清單及載入功能已灰化停用，等待 Firebase 設定完成；Google 登入入口仍可使用，本機匯入／匯出和記錄不受影響。
- 工具沿用 AI-Learning 的 Firebase Google 登入及教師授權；Firebase 網頁設定由 AI-Learning 公開設定檔載入，不在此工具存放 OAuth client secret。
- 重新啟用後，按「連接／重新授權 Google Drive」才會要求 drive.file 權限。只有按「上載新完整備份 ZIP」時，文章、Word 範本、逐頁工作區及掃描／色稿附件才會送到登入者的 Google Drive。
- 每次上載建立一個有日期的新 ZIP，檔案會顯示在「我的雲端硬碟」根目錄。工具只列出它自己建立的備份，不會搜尋其他 Drive 檔案，也不會自動刪除舊版本。其他裝置須使用同一個 Google 帳戶登入；選取備份後按載入，確認後會取代該瀏覽器的本機記錄。
- 如已有未由工具建立的 ZIP，先用一般「匯入 CSV／JSON／完整 ZIP」載入，再上載新完整備份。ZIP 仍可下載到本機，方便校方保存或轉移。
- Drive access token 只保存在目前頁面的記憶體，重新開啟工具後須再次連接。手機請在 Safari 或 Chrome 開啟 HTTPS 公開頁面；內置通訊程式瀏覽器可能阻擋 Google 登入視窗。
- Google Cloud 專案須啟用 Google Drive API，並允許共用 Google OAuth 使用 drive.file 範圍；未完成時 Drive 清單／上載會顯示設定錯誤。完整 ZIP 可能包含學生個人資料，請使用學校核准的 Google 帳戶和 Drive 位置。

## OCR 私隱

PDF／JPG／PNG 合併、PDF 拆頁、原稿圖片預覽、OCR 身份配對和掃描附件保存均在目前瀏覽器處理；選擇檔案不會自動送至 AI 服務。Gemini Web 只會在老師自行貼上圖片／提示或文章後收到內容。完整備份 ZIP 會包含附件，請只存放在校方核准的位置。

MiniMax OCR 和老師修訂都由瀏覽器直接連接 MiniMax API。只有按下相應按鈕後，OCR 圖片或老師修訂文章、自訂提示語和當次 API key 才會傳送至 MiniMax；key 不會寫入本機記錄、備份或公開檔案。OCR 每次限一張、5 MB 以內。請先遵守校方資料處理要求，只傳送必須處理的內容。

也可使用外部 OCR，再把結果貼上工具。OCR 文字及身份仍需人工核實。老師修訂稿另欄保存；批改時檢查錯字、文句通順及格式，保留學生原意，不清楚處請學生確認。

## 批改與定稿流程

1. 匯入正式名單，核實班別、班號、學號、姓名和所屬小學。
2. 在全班表逐位剔選應交張數及紙本已收張數；名冊「2」剔號選 2 張，「1」下方圈號選免交。每次更改會自動保存。
3. 整批匯入 PDF 初稿；可一次選擇多份 PDF，也可混合 JPG／PNG。工具在本機合併及拆頁，再在第三步完成每頁學生配對。
4. 逐頁複製原稿圖片及 OCR 提示到 Gemini，貼回結果並核對。OCR 不會更改第三步配對；確認後把 OCR 原文匯入已配對學生。
5. 在「AI 修訂助手」微調預設提示語，選擇「複製完整提示到 Gemini Web」或輸入 MiniMax API key 直接產生建議。Gemini 結果貼入建議稿後，或 MiniMax 自動填入建議稿後，先由老師核對，再按「採用至老師修訂稿」。下方會比較核對後 OCR 與老師修訂稿：標色文字可點擊查看原稿及修改內容；新增或刪除部分亦會標示。最後檢查錯字、文句和格式，逐項標記批改狀態並保存。
6. 上載彩色封面及內頁，在內頁右頁預覽確認目前學生的修訂文字，調整字體、文字欄寬和文字區高度，並參考行數與佔位判斷是否請學生增減內容。可列印／儲存雙面卡片 PDF，或下載／複製內頁 PNG 給學生抄寫；DOCX 是可選備用匯出。

外部 Word 和 PDF 預覽元件由固定版本 CDN 載入；如未載入，請檢查網絡連線後重新整理。複製原稿頁或卡片內頁圖片需要 HTTPS／localhost 及瀏覽器剪貼簿支援；若不支援，按鈕會改為下載 PNG，再傳給 Gemini 或學生。
