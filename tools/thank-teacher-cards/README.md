# 箋紙濃情謝師恩｜文章核對及卡片工具

在瀏覽器整理學生名單、謝師恩文章 OCR、老師修訂稿及感恩卡。頁面可配合不同班別使用，資料不會預載在公開網站。

## 使用前準備

先準備以下內容，再到「匯入內容清單」匯入：

1. **學生名單 CSV／JSON**：每列至少有「班別、班號」；可加入正式學號、中文／英文姓名、所屬小學、收件老師、應交張數和紙本已收張數。空白應交張數代表待核，`0` 或豁免欄才代表免交。
2. **文章 PDF／JPG／PNG**：在匯入面板可一次選取多份 PDF、JPG 或 PNG；工具按你選取的順序把 PDF 頁面和圖片合併為逐頁工作區，並列出每頁來源檔名。總容量上限 100 MB、合計最多 300 頁。可逐頁下載單頁 PDF 或整批 ZIP；按「產生原稿圖片」後，可用「複製圖片交 Gemini」及旁邊的 OCR 提示逐頁處理。圖片合成、預覽和拆頁均在目前瀏覽器執行。
3. **文章 OCR**：每次把一張頁面圖片和「複製 Gemini OCR 提示」貼到 Gemini，輸出純 JSON，再按下一頁處理。範例：`{"page":1,"class":"1A","classNumber":1,"studentName":"學生姓名","primarySchool":"所屬小學","teacherName":"老師姓名","ocrText":"文章原文","uncertainNotes":["疑字"]}`。把逐頁結果貼入工具後，頁碼必須對應目前工作區。超過 2,800 字的單頁 OCR 會整批拒收並提示分段，不會靜默截短；已匯入頁重新貼入時會略過。工具只按正規化後的「班別＋班號」精確預選名冊學生；未對上的頁面要手動選學生，不能靠姓名或 PDF 順序自動配對。班別格式無法辨認、班號缺漏／無效，或姓名與名冊不同時，不會自動配對，匯入前會提示再次確認。核實後逐頁按「配對並匯入文章」，OCR 原文和單頁 PDF 會一同連到該學生。
4. **Word 範本（可選）**：可使用內置範本，或上載校方 DOCX 範本。範本欄位包括 `{teacherDisplay}`、`{correctedText}`、`{studentName}`、`{studentNameEn}`、`{className}`、`{classNumber}`、`{studentNumber}`、`{primarySchool}` 和 `{activityTitle}`。
5. **彩色卡片設計（可選）**：在「彩色卡片設計」分別選擇彩色封面和內頁圖片。卡面預覽可切換封面／內頁；「列印／儲存卡片 PDF」會輸出兩面，文章和老師稱呼放在內頁的寫字區。這和 DOCX 範本是分開的：DOCX 預覽及匯出仍按已載入的 Word 範本。

名冊收件規則：原名冊「2」欄剔號代表應交 2 張；其他剔號代表 1 張；「1」下方圈號代表免交。掃描頁數不等於紙本收件數。

## 本機資料與匯出／匯入

- 編輯內容會自動保存於目前瀏覽器的本機儲存區，不會送到 Local-tools 網站。
- **JSON 文字備份**包含學生記錄、OCR、逐頁配對及批改狀態，不包含 PDF／色稿影像附件。
- **完整備份 ZIP**包含 JSON 記錄、Word 範本、目前逐頁工作區及記錄實際引用的 PDF／色稿影像附件；未引用附件不會打包。附件總容量上限為 190 MiB，匯出 ZIP 上限為 200 MiB。匯入會先要求確認，再以 ZIP 內容取代目前記錄並匯入附件。若需整理本機未引用附件，使用「檢查／清理未引用附件」；清理前會顯示數量並再次確認，建議先下載完整 ZIP。跨電腦或清理瀏覽器資料前請下載 ZIP。
- **CSV 匯入**可合併名單或文章欄位；未列出的學生會保留。CSV 和文章資料可匯出作表格處理。
- 學生編輯頁可用手機相機拍照或上載 PDF／JPG／PNG，選「補交」加入現行附件，或選「更新內容」令新檔成為現行版本並保留舊版本下載。每名學生頁面會顯示現行原稿圖片預覽；PDF 預覽顯示首頁，下載按鈕仍包含完整附件。附件和版本歷史保存在目前瀏覽器；更新現行掃描頁數不會代替紙本點收張數。
- 按班進度總表即時統計名冊人數、應交及已收張數、完成遞交人數、欠交張數、掃描頁數和老師批改完成數。完成遞交按紙本已收張數計算；免交學生不計入應交人數，待核張數及待點收人數會另行顯示。
- 可逐名匯出 DOCX 感恩卡，亦可預覽卡面和 Word 主要版面、調整字體大小。
- 彩色封面／內頁色稿和學生掃描一樣只保存在目前瀏覽器，沒有放入公開網站檔案。圖片如含學生姓名或聯絡資料，不應直接複製到公開 repo。
- 清除瀏覽器網站資料會刪除本機記錄和掃描附件；請定期下載完整備份 ZIP，並把備份放在學校核准的位置。

## Google Drive 跨裝置備份

- **目前暫停**：Google Drive 上載、雲端備份清單及載入功能已灰化停用，等待 Firebase 設定完成；Google 登入入口仍可使用，本機匯入／匯出和記錄不受影響。
- 工具沿用 AI-Learning 的 Firebase Google 登入及教師授權；Firebase 網頁設定由 AI-Learning 公開設定檔載入，不在此工具存放 OAuth client secret。
- 重新啟用後，按「連接／重新授權 Google Drive」才會要求 drive.file 權限。只有按「上載新完整備份 ZIP」時，文章、Word 範本、逐頁工作區及掃描／色稿附件才會送到登入者的 Google Drive。
- 每次上載建立一個有日期的新 ZIP，檔案會顯示在「我的雲端硬碟」根目錄。工具只列出它自己建立的備份，不會搜尋其他 Drive 檔案，也不會自動刪除舊版本。其他裝置須使用同一個 Google 帳戶登入；選取備份後按載入，確認後會取代該瀏覽器的本機記錄。
- 如已有未由工具建立的 ZIP，先用一般「匯入 CSV／JSON／完整 ZIP」載入，再上載新完整備份。ZIP 仍可下載到本機，方便校方保存或轉移。
- Drive access token 只保存在目前頁面的記憶體，重新開啟工具後須再次連接。手機請在 Safari 或 Chrome 開啟 HTTPS 公開頁面；內置通訊程式瀏覽器可能阻擋 Google 登入視窗。
- Google Cloud 專案須啟用 Google Drive API，並允許共用 Google OAuth 使用 drive.file 範圍；未完成時 Drive 清單／上載會顯示設定錯誤。完整 ZIP 可能包含學生個人資料，請使用學校核准的 Google 帳戶和 Drive 位置。

## OCR 私隱

PDF／JPG／PNG 合併、PDF 拆頁、原稿圖片預覽、OCR 身份配對和掃描附件保存均在目前瀏覽器處理；選擇檔案不會自動送至 OCR 服務。只有你自行把圖片貼到 Gemini，或按「送 MiniMax OCR」時，該頁內容才會傳送至相應服務。完整備份 ZIP 會包含附件，請只存放在校方核准的位置。

MiniMax OCR 由瀏覽器直接連接 MiniMax API。只有按下「送 MiniMax OCR」後，所選 JPEG／PNG／WebP 影像和 API key 才會傳送至 MiniMax；key 不會寫入本機記錄、備份或公開檔案。每次限一張、5 MB 以內。請先遵守校方資料處理要求，只上載必須辨認的頁面，避免把無關的電話或聯絡資料送出。

也可使用外部 OCR，再把結果貼上工具。OCR 文字及身份仍需人工核實。老師修訂稿另欄保存；批改時檢查錯字、文句通順及格式，保留學生原意，不清楚處請學生確認。

## 批改與定稿流程

1. 匯入正式名單，核實班別、班號、學號、姓名和所屬小學。
2. 逐份點收紙本，分開記錄應交張數、已收張數和掃描頁數。
3. 匯入 OCR，核對姓名、老師及疑字，再修正「核對後 OCR」。
4. 在「老師修訂稿」檢查錯字、文句和格式，逐項標記批改狀態。按「複製 Gemini 老師修訂提示」可取得標準修訂指令；它要求保留原意、正面表達、改善錯字與行文，並按原意補上合適結句。把 Gemini 結果貼回「老師修訂稿」後仍須由老師核對。
5. 預覽卡面及 Word，選擇字體大小，再匯出 DOCX，並在 Word 檢查實際分頁。

外部 Word 和 PDF 預覽元件由固定版本 CDN 載入；如未載入，請檢查網絡連線後重新整理。複製頁面圖片需要 HTTPS／localhost 及瀏覽器剪貼簿支援；若不支援，按鈕會改為下載 PNG，再手動附加至 Gemini。
