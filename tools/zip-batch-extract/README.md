# ZIP 批量解壓工具

在瀏覽器本機選取或拖入多個 .zip 檔，可分多次加入清單。按「開始批量解壓並合併」後，工具會逐個處理 ZIP，把每個來源放入以檔名命名的子資料夾，最後產生一個 extracted-YYYYMMDD-HHMM.zip。重名資料夾會加上「(2)」、「(3)」等後綴；輸出 ZIP 根目錄的 _report.txt 會列出每個來源的檔案數、檔名解碼方式和略過項目。

檔案只在本機瀏覽器記憶體處理，不會上載或發出網絡請求。使用前請完整解壓工具套件，再開啟 START-HERE.html 或 tools/zip-batch-extract/index.html。

## 檔名及安全

- ZIP 檔名有 UTF-8 旗標時按 UTF-8 解碼；沒有旗標時，先採用 CRC 相符且 UTF-8 可解碼的 Unicode Path 額外欄位，否則依次嘗試 UTF-8、Big5、GBK。
- 沒有 UTF-8 旗標或有效 Unicode Path 欄位時，Big5 與 GBK 可能無法分辨；香港情況優先用 Big5。
- 加密 ZIP 不受 JSZip 支援；加密、損壞或不支援的 ZIP 會略過，其他 ZIP 繼續處理。
- 含有等於「..」的路徑段、以 / 或磁碟代號開頭或含反斜線的路徑，以及符號連結會略過並列入報告。
- ZIP 內的 ZIP 只會當作一般檔案輸出，不會再次解開。
- 輸出 ZIP 會在根目錄加入 `_report.txt`；來源檔名產生同名資料夾時會自動加上數字後綴。

## 記憶體限制

輸入、解壓內容及合併輸出都在瀏覽器記憶體中。輸入總大小超過 1 GB 時會顯示警告，但仍可繼續；實際可處理容量取決於裝置可用記憶體和瀏覽器，過大的批次可能令瀏覽器變慢或中止。
