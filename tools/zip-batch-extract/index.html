使用及限制

        
    
          
  • 每個 ZIP 會放入以檔名命名的子資料夾；重名時會加上「(2)」、「(3)」等後綴。
    • 
          
  • 有 UTF-8 旗標的檔名用 UTF-8；沒有旗標時會依次嘗試 UTF-8、Big5、GBK。
    • 
          
  • 加密 ZIP、損壞或不支援的 ZIP 會略過，其他檔案仍會處理。
    • 
          
  • 會略過含路徑穿越字串、絕對路徑、磁碟代號、反斜線的項目，以及符號連結。
    • 
          
  • 不會自動解開 ZIP 內的 ZIP；加密 ZIP 不受 JSZip 支援。
    • 
          
  • 檔案及解壓內容都留在瀏覽器記憶體；可處理大小受裝置可用記憶體限制。
    •
