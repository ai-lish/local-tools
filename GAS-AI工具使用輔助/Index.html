三步工作流

先確認環境，再寫提示語，最後才把成果帶回本機檢查。

01

選擇本機引擎

靜態圖片先用 ComfyUI／A1111；影音與原生聲音才進入 H3-Base。模型檔案與權重留在本機。

02

把意圖寫成結構

圖片聚焦主體、姿勢、鏡頭和參數；H3 另外明確寫出鏡頭時間、環境聲和配樂。

03

記錄和人工檢查

保存 model、seed、steps、尺寸、輸出用途與授權狀態；公開前再做身份、版權及安全檢查。

PATH 01 / IMAGE

Stable Diffusion 本機入門

把「動作詞」放進可控的圖片工作流，而不是只追求一個漂亮關鍵字。

ComfyUI 優先

建議路線：ComfyUI

適合想保留節點、模型、VAE、LoRA 和輸出參數的人。先用 Desktop／Portable 或手動安裝其中一條路線，避免同時混裝多套 Python 環境。

  • 先確認 GPU 驅動、VRAM、磁碟空間與 PyTorch 對應版本。
  • 將 checkpoint／safetensors 放入對應的 models/checkpoints 資料夾。
  • 先用官方或可信來源的簡單 workflow 做 smoke test。
  • 每次只改一項：prompt、seed、sampler、steps 或 CFG。

替代路線：AUTOMATIC1111

適合想用較直觀的 txt2img／img2img 介面。Windows 使用者要依官方說明選擇相容的 Python、Git 與 GPU 路線，版本更新前先備份 workflow 和參數紀錄。

部署提醒

下載模型前先閱讀模型卡與授權。不要把真實學校相片、學生資料或行政文件拖進任何不清楚來源的擴充節點。

提示語只是輸入的一部分；沒有 seed 和參數，成果很難比較。

PATH 02 / AUDIO-VISUAL

MiniMax H3 本機入門

H3 的重點不是把圖片 prompt 拉長，而是把整段影音時間線、聲音和參考關係寫清楚。

H3-Base / local 768p

先分清楚兩個 checkpoint

Checkpoint適合任務輸入
FL2VAT2VA、I2VA、FL2VA、L2VA文字；可選 0／1／2 張 keyframe
Ref2VA多模態 reference-to-audio-video文字＋圖片／影片／音訊參考

實際輸入數量、解析度、BF16 及框架支援會隨官方版本更新；部署前以模型卡為準。

本機流程的正確期待

  1. 先下載需要的 task family，不要為了試驗把整個大模型倉庫無差別複製。
  2. 用本機 H3-Base 跑一個 4–8 秒、單一鏡頭的安全合成案例。
  3. 確認音畫同步、鏡頭時間、VRAM 峰值、輸出資料夾及授權紀錄。
  4. 把結果的 prompt／參數匯入本頁「成果紀錄」，不要把素材上傳到 GAS。
離線邊界要寫在 SOP 裡

官方完整系統還包括 H3-Context-IR 及 H3-Regenerate-2K；它們不是這個 GAS 專案的本機模組。嚴格離線時，本頁只協助本機 H3-Base／768p 的提示語和驗證。不要在程式內偷偷加入 API token、外部 URL、Base64 上傳或背景同步。

H3 模式速查

模式、參考圖位置和鏡頭策略要互相對齊。

模式何時使用提示語寫法
T2VA純文字生成影音從 [Shot 1] 開始建立完整畫面與聲音時間線。
I2VA第一幀向前發展第一行標明 <Picture 1> 在 0.00 秒；接著寫連續動作。
FL2VA第一幀走到最後一幀標示兩張圖片對應的時間；用單一連續鏡頭描述中間路徑。
L2VA從合理前狀態收束到最後一幀把 <Picture 1> 放在有效影片時長的最後一刻。
Ref2VA人物／場景／動作／聲音有多個參考依序使用六個官方欄位：subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music。

本機啟動參考

以下只展示命令形狀；由使用者在自己的本機環境執行，不由 GAS 代為執行。

DOWNLOAD / SCOPE THE CHECKPOINT

Hugging Face 下載示例

# 只下載需要的 task family；路徑請改成本機資料夾
hf download MiniMaxAI/MiniMax-H3 --include "model_index.json" "FL2VA/*" --local-dir MiniMax-H3

官方 repo 同時提供 FL2VA／Ref2VA；若要做多模態 reference，再按需要下載 Ref2VA/*。

SGLANG / EXAMPLE SHAPE

本機服務參考

# 官方示例使用多 GPU；請按你的版本及硬體重新確認
sglang serve --model-path MiniMaxAI/MiniMax-H3 --num-gpus 4 --ulysses-degree 4 --performance-mode speed --host 127.0.0.1 --port 30010 --model-variant fl2va

這裡的 127.0.0.1 只代表本機綁定示意；不要為了方便把含敏感素材的服務暴露到公網。
