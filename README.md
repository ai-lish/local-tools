# 少康教學離線工具

這是 `math-lish/local-tools` 對外發布的安全子集，部署於 GitHub Pages：

<https://ai-lish.github.io/local-tools/>

公開首頁是 local-tools 總入口，列出可公開使用的瀏覽器工具及 CloudSAMS CLI 文件。瀏覽器工具會在本機處理使用者選取的檔案；檔案不會上傳到網站伺服器。來源資料、私有 parser 開發文件與測試檔案不放在這個公開 repository。

目前公開項目：

- 教師人力與行政架構單檔工具
- 活動資料分析工具（去識別化結構核對版）
- 圖片像素提升工具
- 相機圖片合併工具
- CloudSAMS SLP PDF 分割 CLI
- CloudSAMS 班相改名 CLI

PDF 工具箱暫未列入公開版，因現有版本仍依賴外部 CDN；完成依賴內置後再公開。
